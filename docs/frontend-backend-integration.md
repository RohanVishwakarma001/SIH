# MediKiosk Frontend-to-Backend Integration Specification

**Platform**: MediKiosk AI Clinical History-Taking & Triage Platform  
**Frontend**: React 19 + TypeScript + Vite + TailwindCSS  
**Backend**: Fastify 4 + TypeScript + PostgreSQL + Prisma ORM + Zod  
**API Prefix**: `/api/v1`

This document details the exact technical mapping between every frontend screen, user action, frontend function, HTTP endpoint, backend controller, service, Prisma model, and frontend state mutation.

---

## Data Schema & Entity Cross-Reference

1. **User / Auth**: Authenticates with sliding JWT access/refresh token pairs. Roles: `PATIENT`, `DOCTOR`, `STAFF`, `ADMIN`.
2. **Patient & PatientSession**: Stores OPD token (`A-104`), ABHA ID (`91-4829-1029-4412`), language preference (`hi`), priority (`urgent`), and current intake step.
3. **Consent**: Explicit records of informed consent under ABDM and DPDP Act 2023 with timestamp, purpose, and language.
4. **ClinicalInterview & InterviewAnswer**: Per-question audit records capturing question code, value, touch/slider/voice type, confidence, and timestamp.
5. **RedFlag & TriageAlert**: Deterministic rule triggers for Acute Coronary Syndrome, Stroke (FAST criteria), Acute Respiratory Failure, and Intractable Pain ($\ge 8/10$).
6. **Document, OCRResult & MedicalEntity**: Prescriptions, lab reports, and discharge summaries with traceable OCR entity corrections.
7. **MedicalTimelineEvent**: Chronological medical history (consultations, previous labs, prescriptions, surgeries).
8. **ClinicalSummary & SummaryRevision**: Versioned clinical summaries with revision history (v1 AI-generated, v2 doctor-edited, v3 doctor-approved).
9. **Consultation & Prescription**: Finalized physician diagnosis, ICD-10 coding, digital prescriptions, and ABDM FHIR R4 Bundle push.
10. **AuditLog**: Immutable compliance logging for all sensitive PHI actions.
